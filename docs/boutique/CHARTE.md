# Boutique : charte validée (octobre 2026)

Maquettes de référence : `planche.html` (s'ouvre dans un navigateur depuis ce dossier, polices du site).

## Couleurs et typographie
- Fond clair `#FFFDFA`, encre `#191919`, jaune `#ffe34d` en petites touches seulement (un mot, un soulignement, un pin). Pas de crème : mal rendu à l'impression.
- Archivo Black (titres), Public Sans (texte), Source Serif italique (catégorie grammaticale), Caveat (écriture à la main). Polices OFL : impression commerciale autorisée.
- Signature en tout petit, dans le dos sous le col : « Vérifié par çavote.fr ».

## Formats
1. **Définition** : le mot en grand, la catégorie en italique, trois traits où la tribu se reconnaît (portrait flatteur avec un défaut assumé), synonymes. Jamais une moquerie que personne n'aurait envie de porter.
2. **Gros titre** : une phrase courte, alignée à gauche, point final.
3. **Série** : même mise en page, dernier mot qui change (« Insoumis. Sauf à ma mère / ma femme / mon mari / ma fille / mon chat… »).
4. **Code + mot** : un chiffre ou une date toujours accompagné d'un mot ou d'un signe qui le rend lisible (« 49.3 / adopté sans vote »). Exception voulue : les codes d'initiés (« 1312 »).
5. **Pins militants** : couleur de famille (grille des nuances du site), un signe, un code.

## Règles
- Chaque camp prend la même dose ; pas de nom de candidat, pas de visage, pas de logo de parti.
- Exclus : nazisme, Vichy, négationnisme, codes haineux, insultes visant une origine, une religion ou une orientation.
- Citations historiques : attribution vérifiée avant impression.
- Vente : Spreadshop (impression à la demande, vendeur Spreadshirt). Numérique : Gumroad.
- Pas de Printful tant que le site reste anonyme : avec Printful, la vendeuse est la personne qui édite le site, et la loi impose alors son identité dans les mentions légales.
- Personnalisation : variantes prêtes à choisir (une variante = un design), jamais de texte libre.
